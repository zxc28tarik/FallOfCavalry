1. **Gerçek Three.js yok.** `FOC_THREE` özelleştirilmiş WebGL mini-uygulaması; özgün G3D-02A-R1 Three.js kaynağının yerini alamaz.

3. Piyade geometri detayı kaynakta arttı; ekranda doğru anatomi, silah kavrayışı, tutarlı normals, shader programı ve tarihsel kalite gerçek WebGL görüntüsünde kontrol edilmedikçe **görsel kabul verilmez**.
4. Batch sayısı 7 yalnız soldier instance gruplarıdır; arazi/çizgi ile toplam GPU draw call daha yüksektir. 7 batch'in GPU'da başarıyla çizildiği gözlenmedi.
