## YENİ ENGELLEYİCİ REGRESYON: KAMERA HER YENİ WALK LEG'İNDE SEKTÖR MERKEZİNE DÖNÜYOR

G3D-03A-R1 `Battle3DRenderer.sync(snapshot,options)` fonksiyonunda:
```js
if (this.cameraController && !options.preserveCamera) {
  this.cameraController.setBoundsAndTarget(derived.bounds, derived.cameraTarget, Boolean(options.snapCamera));
} else if (this.cameraController && options.preserveCamera) {
  this.cameraController.setBoundsAndTarget(derived.bounds, null, false);
}
```
G3D-03A-R2 bunu **yanlışlıkla** aşağıdaki koşulsuz davranışa çevirmiş:
```js
if (this.cameraController) {
  this.cameraController.setBoundsAndTarget(derived.bounds, derived.cameraTarget, Boolean(options.snapCamera));
}
```
`Battle3DPreviewController._onFrameTick()` her yürüyüş aşamasında `this.renderer.sync(previewSnap, {preserveCamera:true})` çağırdığı için `setBoundsAndTarget()`, istenen küme odağını iptal edip `derived.cameraTarget` (sektör merkezi) ile `desired.targetX/Z` değerlerini overwrite ediyor.

**Bağımsız gerçek Chromium ispatı (UI aracılığıyla başlatıldı, sonraki leg bilinçli simüle edilerek kesin an yakalandı):**
```json
{
 "beforeLeg1": {"targetX":-17,"targetZ":-19.87,"distance":35,"yaw":-0.14,"pitch":0.78},
 "afterLeg1": {"targetX":0.1,"targetZ":-3.4,"distance":35,"yaw":-0.14,"pitch":0.78},
```

Bu, 23. test `toggleWalkPreview()` hemen ardından `syncTransform(1)` yapıp yalnız ilk kadrajı saydığı için kaçan bir hata. Kamera açılıştan sonra ilk saniyelerde makul görünse bile daha sonraki snapshot ile sağa/boş araziye kayar. **G3D-03A-R2 bu nedenle BEST'e yükseltilemez.**
