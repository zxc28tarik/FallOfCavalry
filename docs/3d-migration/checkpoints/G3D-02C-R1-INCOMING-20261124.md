## Açık risk / gelecek çalışma
1. Bu HTML **kendi `FOC_THREE` WebGL renderer'ına sahip bağımsız demo**; gerçek Three.js değil ve proje gerçek savaş `SoldierInstance/UnitGroup/SectorManager` runtime'ına bağlı değil. `dataAuthority: existing_battle_simulation` string değeri teknik entegrasyon kanıtı değildir.
2. Fallback overlay gerçek 2D savaş değildir. Oyun ana 2D/3D seçme ve savaş otoritesi entegrasyonu daha sonra yapılmalı.
3. Süvari unknown `activeWeapon` hâlâ varsayılan kılıçlı görsel; veri sadakati için takip.
4. 200 upfront süvari şablonu ve 300 askerin hareket/animasyon GPU güncellemesi hedef cihazlarda ayrıca performans testine tabi olmalı.
5. Test sahnesi statik `state='ready'`; yürüyüş/çarpışma/ateş/AI/hasar hâlen implement edilmedi.
